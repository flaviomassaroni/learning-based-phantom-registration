# Initial problem
Geometric registration: modern strategies adopt ICP which often stalls in suboptimal local minima (adopting heuristic or searching larger parts of SE(3) motion space slow the problem).

# Problem Formulation

Given two point clouds:

X = {x₁, ..., xₙ} ⊂ ℝ³    (source)
Y = {y₁, ..., yₘ} ⊂ ℝ³    (target)

Find the rigid transformation [R, t] with R ∈ SO(3), t ∈ ℝ³ that minimizes:

E(R, t) = 1/N · Σᵢ ‖R·xᵢ + t - yᵢ‖²

If correspondences are known → closed-form SVD solution (Arun 1987).
If correspondences are unknown → chicken-and-egg problem:
m(xᵢ, Y) = argminⱼ ‖R·xᵢ + t - yⱼ‖

to find optimal m, needed (R, t)
to find optimal (R, t), needed m

ICP devides the loop iterating between the two steps (sensible to initialization and converging to local minima).
DCP solves the problem, m from embeddings, differentiable and end-to-end trainable . 

# Solution
Deep Closest Point (DCP), predicts a rigid transformation between two point cloud.
1) Map the input point clouds to permutation embeddings that help identify matching pairs of points
2) An attention based module combining pointer network predicts a soft matching between the point clouds
3) A differentiable singular value decomposition layer predicts the rigin transformation.

# Why DCP Was Needed?
| Method | Note |
|---|---|
| ICP | purely geometric, local optima |
| Go-ICP | globally optimal but very slow |
| Descriptor + RANSAC | two-stage, not end-to-end |
| PointNetLK | end-to-end but no explicit correspondences |
| DGCNN | local features via k-NN graph |
| **DCP** | **end-to-end, learned soft correspondences, differentiable SVD** |

#DCP 
**PointNet:** takes a set of points, embeds each by a nonlinear function from ℝ³ to higher dimensional space, channel-wise aggregation, optionally outputs a global feature vector for the whole point cloud.

**DGCNN:** incorporates local geometry into its representation. Given a set of points, constructs k-NN graph, applies nonlinearity to the values at edge endpoints (obtains edgewise values), performs vertex-wise aggregation.

Choosing DGCNN + Attention (learning co-contextual information)
Pointer generated by probabilistic approach ('soft map' from one point cloud into the other).
SVD Module extracts the rigid motion from the soft matching. Differentiated for backpropagation.
Loss: Loss = ||R_pred^T · R_gt - I||² + ||t_pred - t_gt||² + λ||θ||²
